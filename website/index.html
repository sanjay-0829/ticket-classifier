Architecture

System Architecture

An end-to-end overview of the ML pipeline routing engine.

01

Ingestion Layer

Gateway for incoming customer issues, supporting webhooks, dashboard REST submissions, and email forwarding API gateways.

FastAPI / Uvicorn / JSON API
02

Preprocessing & Vectorization

Regex-based normalization, stopword stripping, lowercasing, tokenization, and high-dimensional TF-IDF vector fitting.

Scikit-Learn / TF-IDF Vectorizer
03

ML Dual-Head Inference

Parallel logistic regression model prediction heads calculate class probability confidence curves for both ticket Category and Urgency in under 50ms.

Python / Scikit-Learn / Pickle
04

Targeted Routing & SLA Orchestration

Dynamic department assignment dispatcher. Instantiates a real-time countdown timer based on urgency, triggering Slack and Jira webhook notifications.

Webhooks / PostgreSQL / Streamlit
